## Datos y reproducibilidad

La base de trabajo es ENSSEX 2022–2023. Existe una validación preliminar local de un CSV convertido desde SAV; su integración y documentación reproducible están pendientes.

Los datos originales y el entorno virtual local no se incluyen en esta versión. Antes de cerrar la entrega se documentarán la fuente, la conversión, las dependencias y los pasos para ejecutar ambos notebooks desde una copia limpia del repositorio.

## Trabajo colaborativo

Cada integrante registrará sus aportes reales desde su propia cuenta mediante commits descriptivos. El historial y la documentación permitirán identificar los cambios y la revisión conjunta.
