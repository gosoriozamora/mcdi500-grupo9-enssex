# Datos originales

En esta carpeta conservamos los archivos de entrada sin modificarlos. Los resultados de la limpieza y transformación se guardarán en `F1/data/processed`.

La validación preliminar está configurada para leer `20241205_enssex_desde_sav.csv`, con separador de punto y coma y codificación `utf-8-sig`. En esta carpeta también se conserva el CSV descargado, `20241205_enssex_data.csv`; no es el archivo utilizado por ese notebook.

El archivo SAV y las notas de la conversión están disponibles en los materiales de trabajo del equipo. Nos falta incorporar al proyecto las instrucciones y el procedimiento para obtener o reconstruir los datos en otro computador.

Los archivos de datos de esta carpeta están excluidos de Git mediante `.gitignore`. Este README sí se compartirá para explicar cómo trabajar con ellos.
