# Antecedente de validación inicial

Conservamos el notebook preliminar y su informe como antecedente docente. La clasificación automática y los umbrales del curso aportan contexto, pero el flujo vigente comienza en `F1/notebooks/F1_Definicion.ipynb` y continúa en F2.

Los archivos históricos conservan sus salidas y rutas originales; no es necesario ejecutarlos para reproducir el proyecto. Para repetir el diagnóstico, trabajar en una copia del notebook desde esta carpeta y cambiar `RUTA` a `../../data/raw/20241205_enssex_desde_sav.csv` e `INFORME` a una ruta nueva, evitando sobrescribir el informe histórico.
