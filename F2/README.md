# Fase 2 · Preparación de datos

En esta fase prepararemos los datos que usaremos en el análisis. Organizaremos el proceso en etapas y explicaremos las decisiones que tomemos.

## Etapas de trabajo

1. Obtener los datos y comprobar que se cargan correctamente.
2. Revisar los tipos de variables, la distribución de sus valores, los datos faltantes y los posibles duplicados.
3. Definir cómo trataremos los problemas encontrados y justificar cada decisión.
4. Organizar el código en funciones, cada una con una tarea específica.
5. Transformar las variables que lo necesiten y explicar si corresponde normalizarlas.
6. Probar las funciones con casos habituales, casos límite y entradas incorrectas. También revisaremos los resultados de cada etapa.
7. Dejar los datos preparados para crear gráficos y continuar el análisis.

## Organización de los archivos

- `notebooks`: notebook de Fase 2, que todavía debemos desarrollar.
- `docs`: decisiones de limpieza y transformación, y resultados de las validaciones.

Usaremos los datos de `F1/data/raw` y guardaremos los resultados en `F1/data/processed`. Las funciones que puedan reutilizarse se ubicarán en `F1/src`. Estas rutas se indican desde la carpeta principal del proyecto.

## Avance

El desarrollo de esta fase está pendiente. Cuando terminemos, ejecutaremos el notebook desde el inicio para comprobar que funciona sin errores y dejaremos los resultados guardados.
